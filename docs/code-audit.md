# 2026-10-04 全项目代码检查

本轮从 `652b10c` 开始，检查仓库自有脚本、LuCI 控制器与模板、前端交互、
构建工具、测试及 VLAN 子模块。翻译、MIB 和 OpenWrt 配置按数据文件检查；
压缩的第三方 JavaScript、IPK、引导程序、驱动和其他预编译组件不等同于其
上游完整源码。构建继续固定底包，并逐项核对受保护二进制。

## 修正与结构调整

| 范围 | 问题与完成的改动 |
| --- | --- |
| 配置读取 | 旧配置页忽略环境读取失败。配置显示、保存、备份恢复共用有超时和长度限制的读取；失败返回 503，阻止保存。一次快照同时提供普通字段、基础启动项和镜像版本默认值。 |
| Hook 文件 | 编辑器和恢复共用检查与原子替换逻辑，处理短写并校验私有目录。备份和导入预览在 RAM 校验语法；正式保存才在持久目录中暂存。读取失败时禁用编辑器保存。 |
| 诊断 | PON、ME、VLAN 查询具有超时和输出上限；失败不返回半截成功结果。连续选择时取消旧请求，迟到响应不会覆盖当前选择。ME 列表先转义设备文本，再生成受控链接。 |
| OMCI 空表与失败 | 实机试启动发现无扩展 VLAN 表被旧解码器视为错误。成功的空表现在返回明确提示；OMCI、属性读取及解析器真正失败时传递非零结果，避免管道和 `local` 赋值掩盖错误。 |
| 页面交互 | 本地存储不可用不再中断初始化或保存。过期或异常的标签名按现有 DOM 逐项匹配；函数内变量不再意外写入全局。 |
| 支持包 | 删除与生成使用同一把锁；原始硬件查询有超时，输出长度受限；不存在的下载返回 404。 |
| 固件信息 | 修正两种旧 banner 的字段位置。读取备用槽元数据与安装器共用锁，缓存原子发布，挂载失败清理临时目录。 |
| 运行辅助函数 | 修正 B 槽软件版本回退、版本 setter 参数检查、BFW setter 对调用者全局变量的依赖、`int8(128)` 符号边界、环境值的字面输出及 MIB 替换中的特殊字符。 |
| 恢复出厂脚本 | 读取失败不生成重置标记、不清除设置；写入失败停止后续清除并保留恢复备份，不执行重启。部分失败需要人工检查备份与现存配置。 |
| 镜像打包 | 原厂构建拒绝位于生成目录中的输入，保留 `out/` 中其他产物。升级包采用固定成员名的暂存目录，避免文件名正则转换，不再修改输入时间戳；失败保留旧包。整片镜像核对组件大小，检查 `ubinize` 和字节序转换结果，完整生成后发布。 |
| 编码与翻译工具 | Base64 采用固件已有的 nixio 编码器，独立 Lua 保留兼容实现。翻译重复键检测改用字典索引，输出缓冲按实际大小增长。 |

共用接口集中在“受限读取”和“验证后提交文件”两个重复边界。字段定义仍由
同一份数据服务于页面与服务端验证；动态状态继续按请求读取，现有 VLAN
监控周期和规则指纹保持原有语义。

## 性能证据

目标设备同进程载入修改前后源码，比较实际字段值和默认值，未写入配置。
完整配置准备各测七次：平均 **529.44 → 361.92 ms**，shell 调用 **9 → 4**，
另有一次带超时的环境读取进程。

对包含全部字节值的 64 KiB 数据，三次测量中位数：

| 操作 | 原 Lua 实现 | nixio 原生实现 |
| --- | --- | --- |
| Base64 编码 | 6328.02 ms | 4.33 ms |
| Base64 解码 | 6994.80 ms | 8.37 ms |

输出逐字节一致。完整配置准备不包含 HTTP 和页面渲染；64 KiB 是较大样本，
不能直接作为普通备份的端到端耗时或网络吞吐收益。

七个现有 PO 文件用新旧编译器逐字节比较，LMO 完全一致。重复检测由二次扫描
变为平均线性查找，总编译仍包含索引排序。主机上三个大目录的编译中位数分别
从 52.32、56.32、50.87 ms 降至 40.29、38.80、32.76 ms；这是构建侧收益。

## 第二轮检查与边界

修改后再次检查共享调用者、异常返回、资源关闭、临时文件、锁范围、写入前
验证、输出发布及浏览器请求顺序。补充实际缺陷的回归，不用重复实现内部算法
的测试替代结果检查。具体测试次数、CI、镜像校验和实机部署状态集中记录在
[验证记录](validation.md)，避免把尚未完成的环节记为通过。

BFW setter、恢复出厂和原厂镜像打包有隔离回归，本轮部署目标仍是 basic。
合成整片镜像测试验证布局、填充、字节序和失败保护，没有执行真实整片烧录。
光纤业务、不同 OLT、真实 Safari/iOS、厂商二进制内部实现仍需对应环境验证。
