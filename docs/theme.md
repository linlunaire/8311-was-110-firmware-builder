# 轻量管理主题

沿用现有 Lua LuCI 与 Bootstrap 菜单，采用 Argon 风格的蓝紫色、侧栏和卡片。
登录、配置、PON 状态、备份与更新页面使用统一样式；小屏幕通过左上角按钮展开导航。

右上角的外观按钮依次切换“跟随系统 → 浅色 → 深色”。选择仅保存在当前浏览器，
不修改猫棒配置；浏览器禁用存储时仍可切换。导航支持键盘展开、Escape 关闭及焦点返回。

使用系统字体与纯色背景，没有新增字体、图片、视频、框架或状态轮询。
页面初次加载新增主题 CSS / JS 两项静态资源；菜单继续使用原生 LuCI 的加载与缓存。
这不代表零开销，固件压缩后的实际增量与设备验证结果见 [验证记录](validation.md)。

新增样式与交互独立编写，保留所修改 Bootstrap 模板的 Apache-2.0 版权与许可声明。
完整 Argon 包没有被安装，也没有为主题更换 LuCI、内核或厂商驱动。

浏览器回归检查外观持久化与系统切换、原生菜单链接、移动导航、320–1280px 布局、
两种外观的文字对比度及存储受限时的行为。目标原生模板渲染、浏览器模拟端点、
构建和实机部署是不同的验证阶段。
