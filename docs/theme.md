# 轻量管理主题

沿用现有 Lua LuCI 与 Bootstrap 菜单，对照 [Argon](https://github.com/jerrykuku/luci-theme-argon)
调整整高侧栏、彩色菜单图标、紫蓝页头与紧凑卡片。深色使用炭灰底色与紫色菜单；
登录页采用靠左的整高面板、下划线输入框和静态渐变背景。
登录表单只保留登录按钮；主题切换固定在屏幕右上角，小屏设备名为它预留空间。
登录、配置、PON 状态、概览、路由、备份与更新页面使用统一样式；小屏幕通过左上角按钮展开导航。

右上角采用太阳、月亮、显示器三个图标，分别直接选择浅色、深色、跟随系统。
选中图标显示圆形底色，支持键盘操作。选择仅保存在当前浏览器，
不修改猫棒配置；浏览器禁用存储时仍可切换。导航支持键盘展开、Escape 关闭及焦点返回。

使用系统字体、内嵌 SVG 菜单图标与 CSS 背景，没有新增字体、图片请求、视频、框架或状态轮询。
页面初次加载新增主题 CSS / JS 两项静态资源；菜单继续使用原生 LuCI 的加载与缓存。
页头提前确定配色，其余主题脚本通过 `defer` 加载，保留深色首屏与原有交互。
备份页的选择框、文件选择和按钮对齐，操作按钮使用主题色，重置按钮使用警示色。
概览的网络框、接口徽标、路由表头均覆盖两种外观；进度条使用蓝紫色细条，
数值与色条分开显示。窄屏路由表可横向滚动，完整保留地址与列名。
页脚致谢页只在访问链接时加载。资源大小、构建及设备验证结果见 [验证记录](validation.md)。

表头、接口框、按钮与进度条移植自 Argon 的 `cascade.less` / `dark.less`，
保留 Jerrykuku、Lutty Yang 与 Apache-2.0 声明。适配旧版 LuCI 的选择器，
稍微加深浅色主按钮背景并分开进度数值与色条，以保持文字可读。
保留所修改 Bootstrap 模板的原版权与许可声明。
完整 Argon 包没有被安装，也没有为主题更换 LuCI、内核或厂商驱动。
页脚显示 linlunaire 的 fork 与维护署名，原作者、翻译者、视觉参考及完整 Apache-2.0
许可保留在页面链接的“版权与致谢”中，源码中的原版权声明保持不变。

浏览器回归检查外观持久化与系统切换、原生菜单链接、移动导航、320–1280px 布局、
两种外观的文字对比度及存储受限时的行为；概览和路由使用随包 LuCI 的真实渲染函数
配合示例数据，备份表单从实际模板提取，检查具体控件的配色和对齐。
实机另用 Edge 登录并验证这三个页面的配色、对齐与窄屏布局，以及三档切换。
目标原生模板渲染、浏览器模拟端点、构建和实机部署是不同的验证阶段。

可读主题源码位于 `tools/theme/8311-theme.css` 和 `tools/theme/8311-theme.js`。
修改后执行 `npm ci --prefix tools/theme --ignore-scripts`，再运行 `npm run build --prefix tools/theme`
生成固件内的压缩资源；`npm run check --prefix tools/theme` 检查生成文件是否一致。
压缩器版本和依赖由 lockfile 固定，版权声明原样保留，压缩工具只在开发环境运行。
