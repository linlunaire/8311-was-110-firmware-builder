还用基线源码复现了两处失败，复现全部在隔离目录中完成：

- 升级归档声明错误 rootfs 哈希时，旧版 `--install --yes` 发生了 3 次模拟 UBI 写入，打印哈希错误后仍返回 0。修改版先验证全部组件，错误输入在任何模拟写入前返回非零。
- stock 镜像的 rootfs 尾部被截断时，旧提取器返回 0，输出的 rootfs 字节却与原组件不符。修改版在替换输出前拒绝累计长度越界；正常镜像逐组件比较字节一致。

可复现入口：

```sh
python3 -m unittest discover -s tests -v
TEST_SHELL=busybox TEST_SHELL_ARGS=sh python3 -m unittest discover -s tests -v
node tests/frontend_smoke.cjs
node tests/status_poll_smoke.cjs
```

浏览器测试需要已安装 Playwright 及 Chromium；可用 `BROWSER_CHANNEL=msedge` 或 `chrome` 选择已安装的对应浏览器。默认使用本地模拟表单；若已有原生模板的模拟渲染结果，可用 `FIRMWARE_FIXTURE_DIR` 指向含 `upload.html` 的目录。第二条是 CI 定义的 Linux/BusyBox 路径，本地 Windows 本轮未执行完整的这一变体。

尚未完成的验证包括：Linux 完整固件构建、远端 GitHub Actions、产物解包复核、刷机和重启、真实 UBI/启动环境写入、断电恢复、PON 注册、Internet 和 IPTV。当前缺少构建所需的原厂镜像组件，且目标设备未接光纤。现有设备配置值不能当作已验证的运营商业务参数。

升级私有暂存会额外占用三个未压缩组件所需的 RAM 存储；多字段 fwenv 保存仍可能部分成功；停止 VLAN 修正不自动撤销既有规则。这些行为与恢复方式见 [README](../README.md)。跨芯片参考设计与迁移边界见 [调研文档](reference-designs.md)。
